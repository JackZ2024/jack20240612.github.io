01 · 适用范围与运营者

本政策适用于由 【待填写：开发者名称】 提供的“YouTube 上传助手”基础版 1.0 Windows 桌面软件，以及介绍该软件的本网站。

本软件使用 YouTube API Services，是独立开发的上传工具，非 Google 或 YouTube 官方产品。Google 和 YouTube 对其服务中的数据处理适用 Google 隐私政策；使用 YouTube 服务还应遵守 YouTube 服务条款。

当前版本没有开发者运营的视频上传服务器。视频通过你电脑上的软件发送到 YouTube。本政策描述的是当前版本的实际行为。

02 · 我们访问和使用哪些数据

数据类型用途与处理方式
所选视频文件软件只读取你指定的文件，用于上传到你授权的 YouTube 频道。不会扫描整个视频目录，也不会另行制作视频副本。
视频信息你填写的标题、简介、标签、可见性、儿童受众声明以及固定的视频分类设置，会随上传请求发送给 YouTube。
频道基本信息Google 授权后，软件读取目标频道的基本信息，并在窗口中显示频道名称，帮助你确认上传目标；不保存频道名称到本地记录。
OAuth 授权令牌用于证明你已授权软件访问相应 API，并在需要时更新访问令牌。软件不读取或保存你的 Google 账号密码。
本地设置与上传结果保存 OAuth JSON 文件路径及最近一次上传的记录，便于恢复设置、显示视频链接和提醒可能的重复上传。

软件只有在你点击“开始上传”后才提交上传任务。打开软件时，若存在有效授权，会自动恢复授权并读取频道信息，不会自动上传视频。

03 · Google 授权权限及使用边界

  • https://www.googleapis.com/auth/youtube.upload：用于上传你选择的视频及其相关信息。
  • https://www.googleapis.com/auth/youtube.readonly：该权限的授权范围允许读取 YouTube 账号信息；当前软件实现只调用频道查询，用于确认目标频道，不读取播放历史、订阅列表或其他视频列表。

授权通过 Google 的浏览器页面完成。你可以拒绝或撤销授权；这会使依赖授权的视频上传和频道确认功能无法使用。

本软件对通过 Google API 获得的信息的使用和向其他应用的转移，将遵守 Google API Services User Data Policy，包括其 Limited Use（有限使用）要求。当前版本不将 Google 用户数据用于广告、出售、用户画像或训练人工智能模型。

04 · 数据保存、安全与保留时间

本地数据位于 Windows 当前用户目录中的 %LOCALAPPDATA%\YouTubeUploadManager\：

  • token.dpapi：OAuth 访问令牌、刷新令牌及相关授权配置。使用 Windows DPAPI 加密，绑定当前 Windows 用户；重新授权或刷新令牌时会更新。
  • settings.json：用户选择的 OAuth 凭据文件路径。以普通 JSON 文件保存，直到被更新或由你删除。
  • last_upload.json：最近一次上传的文件路径、视频标题、简介、标签、可见性、儿童受众声明、任务状态、视频 ID 和错误或结果信息。以普通 JSON 文件保存，每次开始新上传会覆盖之前的记录。

最近一次上传记录也可能包含上传失败时的 API 错误说明。软件不自动定期清除这些文件；你可按下一节的方法随时删除。不建议在简介或标签中填写不希望其他电脑使用者看到的敏感信息。

你选择的 OAuth JSON 凭据原文件仍保留在原位置，软件不将其复制到开发者服务器。加密不能防止同一 Windows 账号下的恶意程序访问数据，也不替代电脑本身的安全防护。卸载或删除软件程序文件，不会自动删除上述用户数据目录。

上传到 YouTube 的视频及其相关信息由 Google 和 YouTube 按其政策处理、存储和保留。删除本地记录不影响 YouTube 上的视频。

05 · 数据传输与第三方分享

授权和上传过程中，软件通过 HTTPS 与 Google OAuth 服务和 YouTube API 通信，发送必要的授权信息、视频文件及视频信息，并接收频道信息、上传状态和视频 ID。

当前桌面软件没有向开发者回传视频、授权令牌、频道信息或上传记录的功能，也没有广告 SDK、行为分析或自动崩溃报告。软件不向其他第三方出售或分享 Google 用户数据。

视频上传后的观看范围取决于你选择的可见性和 YouTube 实际应用的设置：公开视频可供公众观看；非公开视频可通过链接访问；私享视频按 YouTube 的访问规则限制观看。点击“复制链接”会将链接放入系统剪贴板；点击“打开视频”会由默认浏览器访问 YouTube。浏览器、操作系统及其同步设置可能影响剪贴板和浏览记录的处理。

06 · 如何撤销授权和删除数据

  1. 撤销 Google 授权：打开 Google 账号的第三方应用权限页面，找到对应 OAuth 应用名称并移除访问权限。应用名称以 Google 授权页面显示的名称为准；当前版使用用户配置的 OAuth 项目。
  2. 删除本地授权：关闭软件，在资源管理器中输入 %LOCALAPPDATA%\YouTubeUploadManager\，删除 token.dpapi。仅删除本地令牌不会同时撤销 Google 服务器上的授权。
  3. 删除本地记录和设置：删除 last_upload.json 和 settings.json；也可以删除整个 YouTubeUploadManager 用户数据目录。OAuth JSON 原文件需要在你保存它的位置另行删除。
  4. 删除上传的视频：前往 YouTube Studio 管理或删除视频。撤销授权、停止上传或删除本地文件，不会自动删除已经上传的视频。

删除本地数据后，下次使用软件需要重新配置或授权。如曾把数据放入备份或云同步目录，请同时检查相应备份。开发者不能远程删除你电脑上的文件；如需操作帮助，可使用本政策列明的邮箱联系。

07 · 网站访问与主动联系

本网站为静态介绍页面，不提供账号登录、在线上传或表单，不设置 Cookie、不使用浏览器本地存储，也未加入第三方统计、广告、外部字体或视频嵌入。访问外部链接后，第三方网站的数据处理由其自身政策决定。

网站托管服务商可能为了提供页面和保障安全而处理 IP 地址、访问时间、浏览器信息及请求记录。实际托管服务商及其隐私政策为：【待填写：托管服务商名称与隐私政策网址】。

08 · 儿童与上传内容

本软件面向管理自己 YouTube 频道、能够合法使用 Google 和 YouTube 服务的用户，不专门面向儿童。上传时填写“是否面向儿童”属于向 YouTube 声明视频受众，并不代表软件面向儿童提供服务。用户应如实填写，并对上传内容及所需权利负责。
